# Forest rice

i3 + polybar + picom + alacritty + rofi + starship, in a forest palette.

## Restore
    git clone git@github.com:Whit3Unic0rn/dotfiles.git ~/dotfiles
    cd ~/dotfiles
    stow i3 polybar picom alacritty rofi starship fastfetch gtk

Extra files (bashrc, Xresources, LightDM configs) are in `extras/`.
Configs assume the username `kai` (paths like /home/kai/...).
